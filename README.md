# Мотивація/Motivation
Стикнувся з тим, що програми для перегляду стану акумулятора з BLE вимагають від мене вмикання GPS. Це викликало в мене легке роздратування, і я трохи накидав скрипт, який читає стан акумулятора. 

I ran into an issue where apps for checking battery status via BLE require me to enable GPS. This was a bit annoying, so I quickly put together a script to read the battery status.

Add a GUI because I can.
